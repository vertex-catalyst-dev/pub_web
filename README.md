# pub_web

Generador de sitios estáticos con [Hugo](https://gohugo.io) y [Alpine.js](https://alpinejs.dev) para practicar componentes.

- `layouts/partials/components/`: componentes reutilizables (Hugo partial + estado Alpine.js).
- `content/`: contenido en Markdown.

## Uso

    hugo server   # desarrollo en http://localhost:1313
    hugo          # genera el sitio en public/
